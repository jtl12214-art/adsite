여백 추가부터 콜라주, 자르기, 워터마크, 용량 줄이기와 파일 변환까지 필요한 작업을 빠르게 처리해보세요.

이미지 도구

01

여백 추가

사진을 자르지 않고 원하는 비율에 맞춰 여백을 추가합니다.

사용하기 → 02

분할하기

사용하기 → 03

콜라주

여러 장의 사진을 다양한 레이아웃으로 한 장에 구성합니다.

사용하기 → 04

자르기·회전

필요한 영역만 자르고 사진의 방향을 90도 단위로 조정합니다.

사용하기 → 05

모자이크·블러

가리고 싶은 영역에 모자이크, 블러 또는 가리기 효과를 적용합니다.

사용하기 → 06

워터마크

사진 위에 텍스트나 로고 워터마크를 원하는 위치에 추가합니다.

사용하기 → 07

색상 추출

사진을 분석해 대표 색상과 HEX·RGB 값을 확인합니다.

사용하기 → 08

해상도·비율 계산

이미지 해상도와 비율을 확인하고 원하는 크기를 계산합니다.

사용하기 → 09

용량 줄이기

사진 품질을 고려하면서 원하는 목표 용량에 맞게 압축합니다.

사용하기 → 10

파일 변환

간편한 이미지 작업

설치 없이

프로그램을 설치하지 않고 웹 브라우저에서 바로 사용할 수 있습니다.

필요한 기능만

복잡한 편집 프로그램 대신 필요한 이미지 작업을 빠르게 처리할 수 있습니다.

브라우저에서 처리

지원되는 이미지 작업은 사용 중인 브라우저에서 처리됩니다.

사용 방법

  1. 01원하는 이미지 도구 선택
  2. 02사진 업로드 또는 값 입력
  3. 03결과 확인 및 저장
