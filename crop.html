사용 방법

    자르기 비율 선택

    자유 비율 또는 1:1, 4:5, 3:4, 9:16, 16:9 등의 비율을 선택합니다.

    영역·방향 조정

    자르기 영역을 이동하거나 크기를 조정하고 필요하면 사진을 90도 단위로 회전합니다.

  4. 04

    저장

    선택된 실제 픽셀 영역을 PNG 또는 JPEG로 저장합니다.

자주 묻는 질문

자르기 비율을 직접 조절할 수 있나요?

네. 자유 모드에서는 자르기 영역의 각 방향과 모서리를 직접 조절할 수 있습니다.

사진을 몇 도까지 회전할 수 있나요?

왼쪽 또는 오른쪽으로 90도 단위 회전을 지원합니다.

저장하면 이미지가 자동으로 확대되나요?

아니요. 선택한 실제 원본 픽셀 영역을 기준으로 저장하며 작은 이미지를 강제로 확대하지 않습니다.

투명 PNG도 사용할 수 있나요?

네. PNG 저장에서는 투명도를 유지하며 JPEG 저장에서는 투명 영역이 흰색으로 처리됩니다.
